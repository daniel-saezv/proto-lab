# Plantilla

Punto de partida de un repositorio nuevo. Crea el tuyo con **Use this template**.

Trae un [`AGENTS.md`](AGENTS.md) esqueleto, la plantilla de pull request y Dependabot para GitHub Actions. En la primera tarea, el agente completa `AGENTS.md` y sustituye este README por el propósito del proyecto, los requisitos y los comandos de uso.
